# Study Assistant (RAG)

An AI-powered document assistant — upload a PDF, ask questions about it, and get answers grounded in the document with citations back to the source.

## Tech Stack
- **Frontend:** React + TypeScript
- **Backend:** FastAPI (Python)
- **Database:** PostgreSQL + pgvector
- **AI:** LangChain + LLM API (RAG pipeline)
- **Deployment:** Docker, GitHub Actions, Render/Vercel

🚧 In development — currently building out the backend.
